# 软件图标来源与核验

## 当前展示规则

前端只使用 `sources.json` 中标记为 `verified`、且 `software` 与推荐名称完全对应的图标。没有记录、名称不匹配或没有图标时，显示文字缩写，不把官网 favicon 自动视为软件图标。

目前仅 GitHub、Visual Studio Code、Telegram 三项有本轮核验记录。其它仍被数据引用的旧图标暂留但不展示；已移除的四项工具不再保留当前图标文件。原站图标可从 Git 历史追溯。

## 核验流程

1. 从软件官网、明确的官方资产域或作者仓库获取，不使用按名称搜索的随机图片和第三方 favicon 聚合服务。
2. 人工查看：确认是该软件的图标，而非发布平台、厂商品牌、占位符或网站通用标识。官方域名只能证明来源，不能自动证明与软件匹配。
3. 下载到本地，记录软件名称、具体资源 URL、核验日期、转换方式、原始文件 SHA-256 与最终文件 SHA-256。
4. `npm test` 检查推荐名称对应关系、来源字段与最终文件哈希；`npm run build` 会先执行这些测试，防止本地图标被悄悄替换。
5. 更换图标或重新下载时，需重新人工确认和更新记录；不能仅把新哈希填进清单。

哈希只证明文件完整性，不证明商标授权或软件安全。图标用于识别对应项目，仍应遵守品牌和许可要求。

## 本轮发现的旧图标问题

旧提交说明采用 favicon，但没有逐项资源 URL 与核验记录。拼图检查发现：

- `chrome.png` 是 Google 的 G 标，不能代替 Chrome 产品图标。
- `cc-switch.png` 是 GitHub 标识，不能代替 CC Switch。
- `microsoft-authenticator.png`、`windows.png` 是微软通用标识，不能代替 Authenticator 或文件管理器产品图标。
- `zarchiver.png` 是 Google Play 标识，不能代替 ZArchiver。
- `potplayer.png` 是通用灰色字母图形，不能据此认定是 PotPlayer 标识。

这些文件没有被提升为已核验记录。其它旧文件即便外观像正确图标，也不会仅凭印象标记为 verified。

## 软件取舍与图标取舍分开

用户要求不再推荐的酷安、F-Droid、OpenCode、Tailscale 已从当前数据中移除；不是因为图标缺失而移除。其它仍推荐的软件若缺可靠图标，只显示缩写，不影响搜索和访问官方链接。
